# OIBSIP – Java Development Projects

This repository contains projects developed as part of the **OIBSIP Java Development Internship**.

The projects demonstrate practical experience with Java programming, Object-Oriented Programming, console applications, REST APIs, Spring Boot, database integration, and web application development.

## Projects

### 1. ATM Interface

A Java-based console ATM application implementing basic banking operations.

**Key Features:**

* User authentication
* PIN verification
* Login attempt limit
* Balance enquiry
* Cash withdrawal
* Cash deposit
* Fund transfer
* Transaction history
* Account management

**Technology:** Java

[View ATM Interface](./Java-Task3-ATMInterface)

---

### 2. Digital Library Management System

A full-stack web-based library management application developed using Spring Boot, Thymeleaf, JavaScript, and MySQL.

**Key Features:**

* User registration and login
* Admin and User roles
* Book catalogue management
* Add, edit and delete books
* Search and category filtering
* Book issue and return
* Due-date tracking
* Automatic ₹5/day overdue fine
* Advance booking
* Member management
* Fine payment management
* Contact/query management
* User and Admin dashboards
* RESTful APIs
* Session-based access control

**Technology:**

* Java 17
* Spring Boot
* Spring Data JPA
* Hibernate
* Thymeleaf
* HTML5
* CSS3
* JavaScript
* MySQL
* Maven

[View Digital Library](./Digital-Library)
